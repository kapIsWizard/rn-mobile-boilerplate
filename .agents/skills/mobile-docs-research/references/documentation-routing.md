# Documentation routing

| Domain | Interactive preference | Deterministic fallback |
|---|---|---|
| Expo and EAS | Expo documentation/build capability | pinned EAS CLI and official Expo docs |
| React Native | installed source/types and official docs | official release notes and platform source |
| agent-device | installed CLI help and MCP contract | pinned CLI help and official agent-device docs |
| Supabase | project-scoped Supabase capability | migrations, Supabase CLI, and official docs |
| Apple | installed Xcode/tool output | Apple Developer documentation |
| Android | installed Gradle/SDK tool output | Android Developers and Gradle documentation |
| Cryptography and key management | installed library/source, platform security APIs, approved KMS metadata | OWASP MASVS/MASTG, NIST, platform docs, provider KMS docs |
| Sentry | project-scoped observability capability | pinned Sentry CLI/SDK docs |
| Figma | read-only design capability | exported, versioned design reference |

Record the source, applicable version range, verification date, and whether the claim is advisory, testable, or automatically enforceable.
