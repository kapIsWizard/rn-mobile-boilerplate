# Review checklist

- Approved scope, requirement trace, and unexplained files.
- Authentication, authorization, RLS, sensitive data, logging, and secret exposure.
- Data-protection contract, plaintext inventory, library/version, AEAD integrity, nonce uniqueness, AAD, key separation, rotation/recovery, backup/reinstall, and environment isolation.
- Migration safety, uniqueness, retries, concurrency, and offline recovery.
- App identifiers, config plugins, entitlements, permissions, deep links, OTA/runtime compatibility, and native fingerprint.
- iOS and Android lifecycle, back behavior, keyboard, safe areas, appearance, locale, and font scale.
- Loading, empty, error, denial, and recovery states.
- Accessibility semantics, touch targets, focus order, screen reader, and motion.
- Render churn, list virtualization, memory, startup, networking, and image handling.
- Test intent, skipped checks, changed assertions, baseline edits, fixture drift, and flakiness.
- Release notes, rollback, observability, and store/privacy impact.
